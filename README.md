# Habits

A small habit tracker that runs on your phone and keeps all its data on the device.

- **Today**: the habits scheduled for today. Tap the box to mark one done.
- **Calendar**: a month view with a colored dot for each habit on each day
  (filled = done, ring = pending, faded = missed). Tap a day to add or remove a
  habit for just that date, or to mark past days done.
- **Habits**: add a habit as text, choose its weekdays and color, and tap a
  habit to edit or delete it. Export and import backups here too.
- **Consistency bar**: at the top of every screen. Every scheduled day you
  complete pulls the bar toward 100% (green); every day you miss pulls it toward
  0% (red). Each habit has its own small bar too.

It's a Progressive Web App (PWA): plain HTML, CSS, and JavaScript with no build
step and no server-side code. Data is stored in the browser's `localStorage`.

## Files

| File | What it does |
|---|---|
| `index.html` | Page structure |
| `styles.css` | All styling |
| `app.js` | All logic: storage, scheduling, scoring, rendering |
| `sw.js` | Service worker that makes the app work offline |
| `manifest.webmanifest` | Makes it installable (name, icon, colors) |
| `icons/` | App icons (generated by `tools/make-icons.ps1`) |

Settings worth tuning are at the top of `app.js`:
- `SCORE_SPEED` sets how quickly the bar reacts (default `0.12`).
- `SCORE_START` sets where a new habit starts (default `0.5`, which is yellow).

## Run it on your computer

```
python -m http.server 8000
```
Then open http://localhost:8000.

## Put it on your phone

Phones only install web apps served over **HTTPS**, so the app needs to be
hosted once. The free and easiest option is GitHub Pages:

1. Create a GitHub repository and push this folder to it.
2. On GitHub, open the repo and go to **Settings → Pages**. Under "Source"
   choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
3. After about a minute, open `https://<your-username>.github.io/<repo-name>/`
   on your phone.
4. Install it:
   - **Android (Chrome)**: tap ⋮ and choose **Add to Home screen** (or **Install app**).
   - **iPhone (Safari)**: tap Share and choose **Add to Home Screen**.

After that it opens like a normal app and works with no internet connection.
Your habit data never leaves the phone. The hosting only delivers the app's code.

## Updating the app

Edit the files, increase `VERSION` in `sw.js` (for example `habits-v2`), and
push. The phone picks up the new version the next time you open the app while
online. Your data is not affected.

## Backups

Your data lives in the phone's browser storage. Uninstalling the app or
clearing site data for the URL deletes it. Use **Habits → Export backup** now
and then to save a JSON file, and use **Import backup** to restore it.
